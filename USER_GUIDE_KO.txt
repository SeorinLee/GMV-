TikTok GMV / 초대장 조회 무설치 실행본

1. ZIP 파일의 압축을 완전히 풉니다.
2. START_TIKTOK_AUTOMATION.bat을 더블클릭합니다.
3. 잠시 기다리면 기본 브라우저에서 사이트가 열립니다.
4. 처음 사용할 때 사이트의 'TikTok 로그인'에서 Chrome/Edge 로그인을 완료합니다.

Python, Node.js, npm 설치는 필요하지 않습니다. 필요한 실행 환경은 ZIP에 포함되어 있습니다.
Chrome(미국 계정) 또는 Microsoft Edge(영국 계정)가 PC에 설치되어 있어야 합니다.
지원 환경: Windows 10/11 64비트

열린 사이트의 상단 메뉴에서 GMV 조회와 초대장 조회를 선택할 수 있습니다.
두 기능은 하나의 통합 Worker(gmv-worker.exe, 8000번 포트)를 사용합니다.
이전 버전의 invitation-worker(8001번 포트)가 실행 중이면 통합 런처가 자동으로 종료합니다.

주의: ZIP 안에서 바로 실행하지 말고 먼저 전체 압축을 풀어야 합니다.
배포 파일 생성(관리자/개발자용): scripts\build-portable.ps1

종료: STOP_TIKTOK_AUTOMATION.bat
로그: %LOCALAPPDATA%\TikTokGMV\logs
작업/로그인 데이터: %LOCALAPPDATA%\TikTokGMV
